TALENTLENS AI v3.0 — WINDOWS RUN COMMANDS

1. Open CMD inside the extracted TalentLens_AI_FINAL folder.
2. Create environment:
   python -m venv venv
3. Activate:
   venv\Scripts\activate
4. Install:
   python -m pip install -r requirements.txt
5. Test:
   python tests\test_engine.py
   Expected: 8/8 tests passed
6. Evaluate:
   python evaluate.py
7. Start application:
   python app\app.py
8. Open browser:
   http://127.0.0.1:5055

Alternative server command:
   flask --app app.app run --host 127.0.0.1 --port 5055
